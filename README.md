# Week 1 Project — Data Wrangling & Exploratory Data Analysis (DMNN)

## Language and Libraries
This project is implemented in **Python** using a Jupyter Notebook.

Main libraries used:
- **pandas** — data loading, cleaning, aggregation, and analysis
- **numpy** — basic numerical operations
- **matplotlib** — visualisations for exploratory data analysis
- **IPython.display** — rendering tables cleanly inside the notebook

---

## Repository Structure
- `notebooks/`  
  Contains the Week 1 notebook (`.ipynb`).

- `outputs/`  
  Contains any rendered outputs (e.g. exported HTML or figures), if generated.
